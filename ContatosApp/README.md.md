# 📌 ContatosApp – API REST em C#/.NET 8

## Descrição
ContatosApp é uma API REST desenvolvida em ASP.NET Core para gerenciamento de contatos. O sistema oferece funcionalidades básicas de CRUD (Criar, Ler, Atualizar, Deletar) organizadas de forma modular, utilizando boas práticas de arquitetura e documentação.

## Funcionalidades
- Cadastro de contatos
- Listagem de todos os contatos
- Atualização e remoção de contatos
- Estrutura em camadas (Controllers, Models, Repositories)
- Documentação interativa com Swagger

## Tecnologias Utilizadas
- C#
- .NET 8
- ASP.NET Core
- Entity Framework Core
- SQL Server
- Swagger

## Como Executar
1. Clone o repositório
2. Restaure os pacotes com `dotnet restore`
3. Execute a aplicação com `dotnet run`
4. Acesse o Swagger em `https://localhost:{porta}/swagger`

# 📌 ContatosApp – REST API in C#/.NET 8

## Description
ContatosApp is a RESTful API built using ASP.NET Core for managing contacts. It provides basic CRUD (Create, Read, Update, Delete) operations, following best practices in architecture and documentation.

## Features
- Create new contacts
- List all contacts
- Update and delete contacts
- Layered architecture (Controllers, Models, Repositories)
- Interactive documentation with Swagger

## Technologies Used
- C#
- .NET 8
- ASP.NET Core
- Entity Framework Core
- SQL Server
- Swagger

## How to Run
1. Clone the repository
2. Restore packages with `dotnet restore`
3. Run the app using `dotnet run`
4. Access Swagger UI at `https://localhost:{port}/swagger`

This project was developed as part of my portfolio to practice backend development with .NET and showcase my skills for future job opportunities.
