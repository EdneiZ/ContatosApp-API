# ContatosApp-API

A RESTful API built with **.NET 6 (C#)** using Entity Framework and Swagger for managing contacts.

## 🚀 Features

- 📄 Create, edit, and delete contacts
- 🔎 Search contacts by ID and list all
- 🔐 Data validation with Data Annotations
- 🌐 API documentation with Swagger

## 🧰 Technologies

- ASP.NET Core 6
- C#
- Entity Framework Core
- SQL Server
- Swagger / Swashbuckle

## 📁 Structure
ContatosApp-API/ ├── Controllers/ ├── Data/ ├── Models/ ├── Program.cs ├── appsettings.json
